# Employee Management System

A console-based Java application to manage employee records.

## Features
- Add Employee
- Search Employee
- Delete Employee
- Store employee details using arrays and objects

## Technologies Used
- Java
- Object-Oriented Programming (OOP)
- Arrays
- Scanner Class

## How to Run

```bash
javac EmployManaSys.java
java EmployManaSys
```
