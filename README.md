Employee Management System

A full-stack Employee Management System built using Java, Spring Boot, MySQL, and React. The application allows users to manage employee records through a RESTful backend API and an interactive React frontend.

🚧 Project Status: In Development

📌 Overview

The Employee Management System is designed to simplify the process of managing employee information. It provides functionality to add, view, update, delete, and search employee records.

The project demonstrates full-stack development concepts including REST APIs, database integration, frontend-backend communication, and CRUD operations.

🚀 Features
Add new employees
View all employees
Update employee information
Delete employees
Search employees
RESTful API integration
MySQL database integration
React-based frontend
Responsive user interface
Frontend and backend separated into different layers
